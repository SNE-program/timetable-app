# 课表助手

一个**本地优先**的大学课表与上课提醒 App：课表、提醒、任务、出勤、外观 DIY、桌面小组件，
全部在这台设备上完成 —— 不上传、不联网、不需要注册账号，也没有广告与统计 SDK。

两种形态，同一套代码、同一份数据：

| | Android 版（app.timetable.mobile） | 网页版 |
| --- | --- | --- |
| 怎么拿到 | 在 Releases 下载安装包（`timetable-app-vX.Y.Z.apk`） | 打开网址，不用安装 |
| 提醒 | **系统闹钟**：息屏、关掉应用、重启手机之后照样响 | 页面内的通知：**页面保持打开时**准时响 |
| 桌面小组件 | 2×2 / 4×2 | 没有（浏览器无法往桌面放东西） |
| 数据存放 | 应用本地存储 + 内置数据库（存图片） | 浏览器本地存储，约 5 MB |
| 数据互通 | 导出 JSON → 另一端导入 | 同左 |

TypeScript + React + Vite，Android 由 Capacitor 打包。

## 给同学的说明

**网页版（最省事）**

1. 打开 `https://<用户名>.github.io/<仓库名>/` —— 电脑和手机的浏览器都能用；
2. 首次打开有一页说明，读完点「知道了，开始用」；
3. 想收提醒就允许通知权限，并**把这一页留在前台** —— 关掉标签页就不会响，浏览器就是这么规定的。

**Android 版（要后台提醒与桌面小组件就装它）**

1. 在仓库的 **Releases** 页下载安装包 `timetable-app-vX.Y.Z.apk`（GitHub 会去掉资源名里的中文，所以文件名是英文的，装到手机上叫什么随你），传到手机上（微信 / QQ / 数据线都行）；
2. 点开安装。系统可能提示「未知来源应用」—— 允许一次即可，安装完可以关掉这个开关；
3. 首次打开有一页隐私说明，读完点「知道了，开始用」；
4. 建议允许通知权限，否则课前提醒不会响（设置里随时能看到权限的真实状态）。

> 换手机、换浏览器、换工具之前，在「设置 → 课表数据」导出一份 JSON 备份即可完整带走。
> 网页版与 Android 版的数据互通：一边导出、另一边导入。

## 能做什么

**课表**
- 单双周、连堂、不规则周次、多套作息方案；时间轴可无限延伸，不限于一学期
- 本周视图（滑动切周、今日高亮、实时时间线、周统计）与今日视图（下一节课倒计时）
- 长按课程卡直接调课；搜索课程名 / 教师 / 教室 / 任务

**录入**
- 手动添加，或从教务系统导出的 **Excel / CSV** 导入（自动识别表头与列，导入后可一步撤销）
- 同学发来的**分享码**：一段文本复制粘贴即可还原整份课表

**提醒**
- 三级覆盖：全局 → 课程 → 单个时段；每日摘要与作业 DDL 提醒
- Android：交给系统闹钟，息屏、关闭应用、重启手机之后依然准时响
- 网页版：页面内的通知，页面保持打开时准时响 —— 边界写在设置里，不藏着
- 设置里能看到完整排程预览与真实权限状态，并逐条自检提醒在这台设备上靠不靠得住

**任务与考勤**
- 作业 / DDL 清单，逾期高亮，自动进入提醒排程
- 出勤记录：到 / 迟 / 缺 / 假，课程详情里给出勤率

**外观 DIY**
- 内置主题、程序化壁纸、自定义图片、课程色板
- 卡片质感 / 圆角 / 字体 / 字号 / 密度 / 深浅色 / 每周显示几天 / 色盲友好配色
- 主题包与分享码（含图片的主题包用文件分享）

**角色（桌面宠物）**
- 可以放一个小角色在课表界面上：会呼吸、会眨眼，点一下有反应，按住能拖
- 素材自己准备：一张图、一段动图，或一段视频（自动抽帧成动图）
- 应用**不内置任何角色**，也不提供下载渠道；角色包是纯数据，不执行任何代码

**数据与导出**
- 课表长图（可直接发群里）、ICS 日历、CSV / Markdown、完整 JSON 备份
- 桌面小组件 2×2（下一节课 + 倒计时）与 4×2（今天剩下的课）—— Android 版
- 插件系统：插件只提供声明式数据，不执行代码，可启用 / 停用 / 授权 / 卸载

## 三条底线

1. **时间引擎必须正确** —— 单双周 / 跨年 / 调停补课 / 无限时间轴都有测试锁死
2. **提醒必须准时，做不到的也要说清楚** —— Android 走系统闹钟，网页版只能靠页面内通知；
   两个版本都在应用内提供「提醒可靠性检查」，逐项确认，做不到的项如实写明
3. **数据属于用户** —— 本地优先、可完整导出、无广告无追踪

## 网页版：部署与差异

网页版是同一个 `src/` 的产物，只是不套 Capacitor 壳。

**发布到 GitHub Pages**

1. 把代码推到 GitHub（默认分支 `main`）；
2. 仓库 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**；
3. 之后每次推到 `main`，`.github/workflows/web.yml` 会自动跑测试、构建，
   并把 `dist/` 发布到 `https://<用户名>.github.io/<仓库名>/`。

构建时会把仓库地址注入页面（GitHub Actions 自带 `GITHUB_REPOSITORY`），
于是网页版里会出现「获取 Android 版」的入口，指向本仓库的 Releases。
本地构建默认没有这个值，入口会自动隐藏 —— 不会出现打不开的死链。
要本地验证，设 `VITE_REPO_URL=https://github.com/<用户名>/<仓库名>` 再构建。

**构建产物用相对路径**（`base: './'`），所以项目页子路径与 Capacitor 的 `https://localhost/` 共用一份产物。
安卓包里也带着同一份网页版，只是多套了一层原生能力（系统闹钟、小组件、分享面板）。

**网页版有哪些、没有哪些**

| 功能 | 网页版 |
| --- | --- |
| 课表 / 今日 / 任务 / 出勤 / 搜索 / 调课 / 停课 | 一样 |
| Excel / CSV / ICS / JSON / 主题包 / 角色包 / 分享码 | 一样（导出走浏览器下载） |
| 外观 DIY、角色（含视频抽帧、走动、翻面、快捷菜单） | 一样 |
| 声明式插件、说明书、更新日志 | 一样 |
| 提醒 | **只在页面保持打开时有效**；设置页与说明书都写明了 |
| 桌面小组件 | 没有（系统能力，浏览器无对应实现），面板里说明并给出 Android 版入口 |
| 电池优化 / 自启动 / 精确闹钟授权 | 没有（Android 专有权限），面板整块换成「网页版的提醒边界」 |
| 提醒可靠性检查 | 换成三项：通知权限、页面开着时是否准时、以及「关掉页面就不会响」 |
| 图片与数据 | 与结构化数据共用浏览器配额（约 5 MB），大图会更快撞到上限 |

按平台分支的文案集中在 `src/app/meta.ts`、`src/ui/WebReminderPanel.tsx` 与几个面板里，
判据只有一个 `isNativePlatform()`，不存在「网页版看起来像 Android」的第三种状态。

## 开发

```
npm install
npm run dev            # 开发服务器
npm test               # 单元测试（455 个用例）
npm run build          # 产出静态文件到 dist/（网页版与 Android 共用）
npm run preview        # 本地预览 dist/（:4173）
npm run sync:android   # 构建前端并同步到 android/
npm run open:android   # 用 Android Studio 打开
npm run apk            # 构建 release APK（需要 ANDROID_HOME / JAVA_HOME）
npm run check:version  # 校验 package.json 与 build.gradle 版本一致
```

### 调试参数

| 参数 | 作用 |
| --- | --- |
| `?tab=today\|tasks\|studio\|settings` | 打开指定页面 |
| `?demo=1` | 载入示例课表（含一处刻意的撞课，用来演示冲突提示） |
| `?debug=1` | 直接打开「排查工具」，省得每次手点开关 |
| `?week=500` | 直接跳到第 500 周 |
| `?open=scheme\|search\|override\|course\|task\|export\|share\|manual\|changelog` | 直接打开对应弹层 |
| `?open=import-sheet&sample=1..4` | 导入向导的内置样例（1/3 矩阵、2/4 长表） |
| `?diag=1&w=320,360,390` | **布局自检**：在指定宽度的 iframe 里测量溢出 / 触控尺寸 / 字号 |
| `?diag=1&text=.panel` | 把匹配到的**渲染后文字**回传（配合 `?report=` 用，检查平台分支到底渲染了哪一支） |
| `?report=4199` | 把检查结果用 1×1 图片信标回传到本机端口（只在带这个参数时联网） |
| `?fs=1.6` | 直接把字号放大到上限之外，验证「大字号不破版」 |
| `?mascot=1\|2\|3\|4\|5\|6` | 示例角色（静态图 / 逐帧图 / 动图 / 半满网格带帧数 / 不带帧数 / 三种状态各一张） |
| `?frame=N` | 逐帧图冻在第 N 帧，用于逐帧核对 |
| `?framecheck=1` | 逐帧播放检查：量「露出来的是不是该露的那一格」 |
| `?behavecheck=秒数` | 角色行为检查：统计做了哪些微动作、反应几次、**锚点有没有越界** |
| `?poke=N` | 让它自己每 4 秒被点一下（验证反应动画） |
| `?mpos=0.95,0.6` | 把角色放到指定锚点（验证贴边时的行为） |

### 目录

```
src/core       时间引擎、数据模型、迁移、导入导出、提醒规则
src/platform   平台层：原生桥、通知（Android / 浏览器）、保存与分享、小组件
src/storage    资产库（SQLite / localStorage）与本地存储
src/theme      主题令牌、主题包、图片与视频管线
src/mascot     角色包格式、摆放规则、逐帧图定位
src/ui         全部界面
android/       原生壳、桌面小组件、通知通道
.github/       Pages 发布工作流
docs/          工程笔记（见下表）
```
