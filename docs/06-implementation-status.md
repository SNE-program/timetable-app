上一版盘点停在 v0.5.0，那时写着"SQLite 未实现、桌面小组件未实现、插件全部未实现、
出勤未实现、CI 未实现、106 个用例"。这些**后来都做了**，但文档没跟上，
一度导致我自己在排期时把已经完成的东西又列了一遍。

这一版是按代码逐项重新对的。凡是标"已完成"的，都能在下面的"证据"列里找到对应文件或验证方式。

（`src/plugins/`，21 个用例），但：

- **只有 `export` 一类能力**。计划书 §7.1 规划的五类扩展点（Importer / Widget / Channel / Theme / AIProvider）都没做；
- 插件是**纯数据**，不执行任何代码 —— 这是刻意的安全取舍，理由写在 `src/plugins/types.ts` 顶部。

要做 Importer / Channel，需要先想清楚沙箱，不是加一个 union 成员那么简单。

## 12. 已知问题

| 问题 | 影响 | 处理 |
| --- | --- | --- |
| 撤销栈只在内存里 | 关掉应用即清空，AI 接入后无法审计 | 列入 P2（ChangeSet 落库） |
| 实体没有 `source` / `confidence` | AI 录入的内容无法标"待确认" | 列入 P2 |
| 改时间 / 切时区后不重排 | 旅行或手改时间后，提醒可能按旧的绝对时刻响 | 本轮修 |
| 提醒准点率未实测 | 计划书 M0 的唯一验收缺口 | 需要真机跑 8 项 |
| 冷启动耗时未测 | 计划书要求 ≤1.2 秒 | 无埋点，可加 |
| 浏览器通知依赖页面存活 | 关掉标签页就不响 | 设置页如实标注 |
| 图片资产依赖 SQLite 插件 | 插件初始化失败会退回 localStorage（有配额风险与提示） | 有降级与提示，不再处理 |
| `?demo=1` 在已有本地偏好的 profile 里不生效 | 只影响开发自检，需要每次用全新 profile | 开发参数，暂不改 |
| 动态 import 分块 | 产物里有 1 个 9.4 KB 的 `web-*.js`（@capacitor-community/sqlite 自带的网页兜底），安卓上永远不会被执行 | v0.9.9 的 APK 里同样是 9.4 KB，非本轮引入 |
